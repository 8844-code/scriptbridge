# 小红书配图实战SOP — 无需设计基础

> 给RJ的配图指南：文案强，但配图是瓶颈 → 用工具+模板，系统性提升

**核心理念：小红书配图不是"美术作品"，而是"信息设计"。逻辑清晰比视觉华丽更重要。**

---

## 第一步：选工具（无需学设计）

### ✅ 推荐：Canva Pro（最佳选择）

**为什么选它：**
- 无需设计基础，模板库海量
- 小红书专用的模板和尺寸（1:1.2）
- 能快速迭代（改文字、换图片、调颜色）
- 月9块钱左右，或买年卡

**快速上手：**
1. 注册 Canva（中文版）
2. 搜索"小红书" → 会出现专用模板库
3. 选一个喜欢的模板 → 改文字 + 换图片 → 导出

**我的建议：** 先花2小时探索Canva的"小红书"模板库，挑出5-10个"这个风格我能接受"的模板，收藏起来。以后每次都在这些模板基础上改，速度会快10倍。

## 第二步：素材来源（找图片、图表、icon）

### 📸 高清图片

**免费渠道：**
- **Unsplash**（unsplash.com）— 高质量无版权图片，搜索"creator""work""story"
- **Pexels**（pexels.com）— 同上，质量也很好
- **Pixabay**（pixabay.com）— 中文友好
- **小红书官方素材库** — Canva里集成了，可直接用

**建议：** 为"短剧、创作者、微信、办公"这些核心关键词各存10-15张高质量图片到本地文件夹，以后配图时直接拖入。

### 📊 图表 + 数据可视化

**数据图表怎么做：**
- **Canva内置** → 搜"chart"或"infographic" → 输入数据 → 自动生成（推荐！）
- **Infogram**（infogram.com）→ 专门做数据可视化，质感很高
- **手动设计** → 在Canva里用形状 + 文字拼（如果你想节省钱）

**例子（你会用到）：**
- 数字对比：373亿 vs 创作者分到多少
- 流程图：微信群撮合 → 交付 → 消失
- 对标对比：现在 vs 未来

### 🎨 Icon + 装饰元素

**来源：**
- **Canva内置** → 搜索任何icon，直接拖入（最快）
- **Iconfont**（iconfont.cn）— 中文icon库，质量高，可下载
- **Feathericons** → 极简风icon

**你需要的icon类型：**
- ✅ 对勾（正面、成功）
- ❌ 叉号（问题、痛点）
- 💰 金钱相关
- 📋 合同相关
- 🔐 安全相关
- 📱 微信、通讯相关

## 第三步：配图的逻辑框架

### 小红书配图的通用套路（这才是最重要的！）

**不管什么主题，6张图的逻辑大致是：**

```
图1：封面 / 首图 = 吸引眼球
  ↓
图2-3：问题 / 痛点展开 = 引起共鸣
  ↓
图4-5：解决方案 / 观点 = 核心价值
  ↓
图6：行动 / 互动 CTA = 激发评论
```

## 第四步：具体配图步骤（用你的内容举例）

### 案例：剧本被白嫖3次 → 现在要重新做配图

**Step 1：打开Canva，搜"小红书 白色背景"或"小红书 极简"**

找一个这样的模板框架：
- 背景：纯色或渐变（建议用你的品牌色：珊瑚红）
- 可以放大标题
- 可以放小段文字
- 留出放图片的位置

**Step 2：为每一张设计逻辑**

| 张次 | 设计思路 | 具体怎么做 |
|------|---------|---------|
| **图1** | **标题封面** | 大字"写剧本被白嫖3次之后" + 小字"我决定做一件事" / 背景用珊瑚红 / 右下角可以放一个"生气"或"觉醒"的emoji |
| **图2** | **问题展开** | 文字："朋友A：被欠2000 / 朋友B：被欠五位数 / 朋友C：无合同，对方消失" / 左边文字，右边放3张"伤心"相关的icon或表情 |
| **图3** | **现状痛点** | 标题："现在的剧本交易是这样的" / 中间大字三行："微信群撮合" / "无合同保护" / "无版权存证" / 左边配一个"微信图标" + "混乱感"的装饰线 |
| **图4** | **解决方案** | 标题："我在做的是" / 三个并排的块：①版权存证（锁icon） ②资金托管（钱包icon） ③标准合同（纸icon） / 每个块用不同颜色 |
| **图5** | **核心观点** | 大字居中："创作者不该靠运气拿到钱" / 背景用珊瑚红的浅色 / 下方小字："这是基本权益" |
| **图6** | **CTA** | "内测中，点击主页链接报名" / 或者做一个"评论区见"的感觉 / 用emoji（👇 或 💬）引导 |

**Step 3：具体操作流程**

1. 打开 Canva，选择"小红书"模板
2. **图1**：Canva模板 → 改标题文字 → 改背景色（珊瑚红） → 保存
3. **图2**：新建幻灯片 → 找一个"列表型"模板 → 输入三行文字 → 右边拖入icon → 调整 → 保存
4. **图3-6**：重复上面的流程

**总耗时：6张图，第一次大概30-45分钟，以后会快到15分钟。**

## 第五步：素材库建设（一次投入，持续用）

### 为你自己建立素材库

创建一个本地文件夹：`03 上线推广/小红书/素材库/`，包含：

```
素材库/
├── 图片/
│   ├── 创作者相关/          （工作、思考、创意画面）
│   ├── 社交相关/            （微信、交流、人物）
│   └── 成功相关/            （对勾、成功、正面）
├── Icon/
│   ├── 正面（对勾、OK）
│   ├── 问题（叉号、警告）
│   ├── 功能（锁、钱包、纸）
│   └── 其他（微信、链接）
└── 颜色参考/
    └── 品牌色板（珊瑚红为主）
```

**建议花2小时做这个一次性投入，以后每次都快。**

## 第六步：配图质感的三个核心

### ✅ 做得好的配图有这三点

1. **信息清晰**
   - 一张图只表达一个主要观点
   - 字体大小有层级（标题 > 副标题 > 正文）
   - 不要超过3种颜色

2. **视觉平衡**
   - 不要全是文字，要"文字+图片+空白"的混合
   - 用icon和emoji来"打破"大段文字
   - 空白不是浪费，是让眼睛休息

3. **品牌一致**
   - 每张图的颜色、字体风格保持一致
   - 建立自己的"视觉指纹"（用户看到就知道是你）

## 第七步：迭代优化

### 每发一条，要记录：

```
配图的哪一张获得最多点击？
→ 点赞高的，可能是这张图最吸引人
→ 下次就多用这种风格
```

**例如：**
- 如果图2（问题展开）的点赞多 → 说明"痛点故事"最能吸引创作者 → 下次加强这块
- 如果图4（解决方案）的评论多 → 说明方案本身容易引起讨论 → 下次多做"对比"和"未来想象"

## 困惑时的快速解决方案

| 遇到的问题 | 怎么解决 |
|-----------|---------|
| "不知道用什么颜色" | Canva里选一个整体配色方案，所有图都用它 |
| "图片找不到" | Unsplash搜"creator work"或"storytelling"，选前3张 |
| "字太多了显得乱" | 减一半的字，加icon或表情 |
| "对比不出来" | 用色块、用大小对比、用emoji标记 |
| "看起来很low" | 减少装饰，留更多空白，用大字 |

## 小贴士：配图时的心理建设

**你不需要做成：** 高级设计师的精美海报

**你需要做成：** 清晰、有逻辑、让人一眼看懂的信息板

小红书用户滑图的速度很快（平均3秒一张），**所以配图的目标不是"美"，而是"快速传达信息"。**

你文案写得好，说明你能组织逻辑。配图就是把这个逻辑**视觉化**。用工具 + 模板，这完全可以学会。
